# Privacy

PDF to Markdown Native processes data inside Obsidian.

The plugin:

- does not make network requests;
- does not use analytics or telemetry;
- does not use an external conversion service;
- does not read or write files outside the active Vault;
- does not save PDF passwords;
- stores only the plugin settings that the user selects.

PDF bytes, generated image data, and PDF passwords can exist in memory during conversion. Obsidian and the operating system control that memory.
